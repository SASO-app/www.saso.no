# SASO Eiendom

Nettside for SASO Eiendom – utleie, salg og forvaltning av bolig- og
næringseiendom. Én-sides scroll-oppsett bygget med React, Vite og
Tailwind CSS v4.

## Utvikling

```bash
npm install
npm run dev
```

## Bygg

```bash
npm run build
```

## Deploy

Siden er satt opp for automatisk deploy på Netlify fra `main`-branchen
(se `netlify.toml`). Kontaktskjemaet i kontaktseksjonen bruker Netlify
Forms.
